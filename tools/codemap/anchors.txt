# codemap bookmarks: NAME <TAB> TARGET <TAB> NOTE
#
#   python3 tools/codemap/codemap.py anchors           # every bookmark -> file:line
#   python3 tools/codemap/codemap.py jump enforce      # one bookmark, with its note
#   python3 tools/codemap/codemap.py anchors --check   # exit 1 if any bookmark no longer resolves
#
# TARGET is either
#   symbol:NAME            resolved through the index (a qualified name or a `::` suffix)
#   grep:FILE:REGEX        resolved by reading FILE now (no index needed); every match is listed
# A bookmark names a place a reviewer keeps coming back to. Put the reason in the
# NOTE: a bookmark that says only where is a search result, not a bookmark.
# Converging points come from docs/message-map.md section 2; gates from CLAUDE.md.
