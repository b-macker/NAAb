# How the mid-run reload ratchet treats govern.json keys it does not NAME.
#
# Read by tools/ratchet_coverage.py and pinned by test_ratchet_coverage.sh.
# A key the ratchet names in a string literal (its violation/notice text)
# is credited automatically; this file covers the rest:
#
#   <key>  ratchet "<token>"   compared, under a message that does not spell
#                              the key out; <token> MUST appear in a string
#                              literal of the ratchet code, or the entry is
#                              reported "hollow"
#   <key>  inert    -- why     parsed, and nothing consults it
#   <key>  startup  -- why     read once before the program runs; a reload
#                              cannot change its effect
#   <key>  neutral  -- why     changes no enforcement in either direction
#
# Every other key the loader reads is UNCLASSIFIED and listed in
# ratchet_unclassified_baseline.txt -- the debt, which may only shrink. Moving
# a key from there to here is a claim: an inert/startup/neutral line needs a
# reason that says how it was established (traced, or observed), and a ratchet
# line needs a reload test, because "named" proves the ratchet MENTIONS a key,
# not that it compares it in the right direction.

# --- Live guidance (docs/plan-live-guidance.md) ------------------------------
# Guidance is text delivered to agents and appended to block messages; it
# grants no capability and moves no level, threshold or gate (traced: its only
# readers are governance_guidance.cpp, the agentSend injection site, enforce()'s
# message suffix and the write refusal below). The one refusal it adds -- the
# governed program may not WRITE a declared source -- exists only while the file
# is a source: a reload that drops the source (or disables guidance) drops the
# reason too, because the file no longer reaches any agent. So no direction of

# Connectors (slice 3a). An https source is held to the LIVE capabilities.network
# on every fetch (governance_guidance.cpp fetchHttps -> networkPolicyDenial), so
# a reload that tightens the network policy stops the next refresh, and one that
# changes the URL changes only which document is fetched under the same policy.
# A command source is an operator program run like a hook: given nothing from
# the run (empty stdin, the load-time environment), it hands the program only
# text, so declaring one grants the program nothing; reloads are signed.
guidance.sources.<sname>.url             neutral -- traced: which document is fetched; every fetch is judged against the live network policy
guidance.sources.<sname>.command         neutral -- traced: an operator program run with operator authority, given nothing from the run; the program receives only its text
guidance.sources.<sname>.auth_env        neutral -- traced: names a credential sent to the source; the name is ADDED to env_vars.blocked_read for the rest of the run (grow-only), never removed
guidance.sources.<sname>.refresh_seconds neutral -- traced: how often the cached copy is refreshed (minimum 5 s); no check reads it
