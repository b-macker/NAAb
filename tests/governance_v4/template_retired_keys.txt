# Template keys that loadFromJson() never parses (A175(b), Bundle 19 PR 4).
#
# `python3 tools/template_coverage.py --unread` lists the template keys with no
# read path in the loader. On 36e09b37 it listed 140. Each was traced by hand
# across every reader of govern.json, not only loadFromJson(): the scanner's
# own loader, agent review, project context, the REST server, the reload's
# evaluateReload() and the raw-JSON declared-order ratchet. Each key's quoted
# name was searched in every source file, and no reader builds a key name at
# run time (no "_level" or "detect_" concatenation; checked by grep).
#
# Four are read elsewhere and stay in the template (READ ELSEWHERE, pinned by
# test_template_coverage.sh TC-07: `--unread` must print exactly these). The
# other 136 are parsed by nothing. By the owner's decision 6 (Bundle 19, the
# settings-liveness step-3 rule): a key that asks for a refusal, a detection,
# a limit, an isolation, an integrity check or an evidence record that nothing
# provides gets a load warning (WARNED); the rest leave the template and
# `naab-lang init` quietly (MOVED OUT). None is wired.
#
# tools/config_known_keys.py reads the WARNED and MOVED OUT groups, so the
# nested unknown-key validator keeps accepting these keys: a config written by
# an earlier `naab-lang init` still loads, warned only where it asks for
# something it does not get. test_no_effect_settings.sh reads the WARNED group
# and compares it with the loader's table (warnNoEffectSettings(),
# governance_config.cpp) by behaviour.
#
# FORMAT. `*` is any key of an object (a language name), `[]` any element of an
# array. A WARNED line is `PATH ASK`: the warning fires only when the value
# asks for the effect --
#   any       the key is present
#   true      the value is boolean true
#   false     the value is boolean false (an allow_* switch asking for less)
#   positive  the value is a number above 0 (a limit)
#   nonempty  the value is a non-empty array or string (patterns to add)
# A value that asks for nothing (false, 0, []) draws no warning: a config that
# writes the template's old defaults is told only about what it asked for.
